# Express.js ბექენდ პროექტი

## გაშვება

```bash
npm install
npm start
```

სერვერი გაეშვება `http://localhost:3001` მისამართზე.

## GET მარშრუტები

- `GET /user` — აბრუნებს JSONPlaceholder-იდან მიღებულ მომხმარებელს (`/users/1`).
- `GET /projects` — აბრუნებს პროექტების მასივს.
- `GET /about` — აბრუნებს სერვერის შესახებ ტექსტს.
